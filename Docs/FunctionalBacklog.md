# Functional Backlog

Super Flat is now implemented as the public Singleplayer test-world entry, with a flat 2 km surface, collision, spawn and native load/return flow. The two original worlds remain design references. See [SuperFlat.md](SuperFlat.md). The older menu-only status below predates the concurrent FPS foundation work.

## Implemented Batch

Fullscreen (borderless), Max Framerate, VSync, GUI Scale and Menu Background Blur are implemented with persistence and confirmed preference reset. Quit Game performs normal standalone shutdown after settings drain/flush and protects the editor. Seven movement binding settings and two Hold/Toggle policies are native and persistent; actual character movement remains pending. See Keybindings.md, VideoSettings.md and QuitGame.md for scope, evidence and remaining human gates.

## Deferred Controls

The JSON registry is the per-control scope record. These effects remain pending even where their choices now save natively. The new preference store remembers 101 scalar choices plus language, resource-pack order, warning dismissal and the extra telemetry choice; see MenuPreferences.md. Minecraft-only concepts need an explicit design decision; native API availability alone is not acceptance. Exclusive fullscreen and monitor video-mode selection remain deferred.

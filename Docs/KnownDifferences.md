# Known Differences

- 102 additional scalar preferences (Master Volume and Bass applied in game since survival step 13a2), language, resource-pack order, warning dismissal and the extra telemetry choice are now saved. Their gameplay/presentation effects remain pending unless listed as implemented below. This supersedes earlier descriptions of these values as document-only mocks. PIE/session-only launches use temporary defaults; standalone launches persist. Dormant bindings, server favorites and durable world drafts remain deferred. See MenuPreferences.md.

- Seven movement bindings and the two Hold/Toggle policies are native and persistent; Shift now sprints and C crouches. Crouch replaces the source's Sneak label, and the other 55 binding rows are Planned and disabled. See Keybindings.md. Actual character movement remains a future acceptance gate. Input v2 fixes the reproduced Unreal Windows CEF key-code capture failure; see the follow-up verification record for the native Windows test status.

- Comparison authority is the supplied browser prototype and its captures, not independently verified native Minecraft screenshots. The reference itself records native Windows visual parity as an open gap.
- Panorama angle/splash phase are frozen for current captures, while the supplied JPEG captures show other moving frames. Moving regions are excluded from visual judgment. Ordinary presentation animation was separately verified to change pixels.
- UI bounds, ordering, sprites and fonts match the supplied source. Visual comparison shows a small text-baseline/rasterization difference between the supplied JPEG/browser captures and Unreal's embedded Chromium, approximately one logical pixel in some labels. JPEG compression also prevents byte-exact comparison. No pixel-perfect native Minecraft claim is made.
- Native Play-in-Editor floating-window capture measured a browser client of 1280x722, not its requested nominal 1280x720; it is evidence of real Slate composition only. The packaged runs use and assert exact client dimensions for both comparison profiles. Editor-hosted `-game` also verified exact 1920x1080.
- Browser-level mouse, keyboard, wheel, fields and key capture passed using CEF's supported diagnostics. Physical OS keyboard/mouse feel through Unreal's focus layer needs a human pass. SlateInspector's synthetic PressKey creates events with native key code zero, so its success return cannot establish CEF keyboard acceptance; this limitation was not counted as a passing input test.
- Experimental editor-only toolset Python initialization reports missing AgentSkill/PythonTestRunner when launching the editor executable in `-game` mode. They are engine tooling messages, not menu JavaScript/module failures; the normal editor connection and packaged menu work. Runtime packages do not include these editor toolsets.
- Fullscreen, engine frame limit, VSync, GUI scale and menu blur are implemented with persistence and confirmed preference reset. Exclusive monitor video-mode enumeration and the source minecart-rotation option remain intentionally disabled. Other graphics options, audio devices, language/font/contrast presentation, account actions, networking, telemetry, files, clipboard and world operations remain mocks. Hard Reset does not delete world/save data.
- The packaged application is Development Win64 on this machine. Shipping builds, other operating systems, multi-monitor/DPI combinations and distribution licensing have not been accepted. Source Minecraft asset/branding rights still apply.
- Quit Game now exits the standalone game normally instead of showing the source's mock Game closed route. It is disabled in editor Play, and a final-save failure cancels exit so preferences are not silently lost. Future gameplay/world save lifecycle has not been implemented.
- Minecraft Realms, Join Realm, all their controls/endpoints and the Online Settings Realms news/invites option are deliberately removed. The main menu closes that row. The immutable reference, unused translation/asset metadata and historical candidates still contain original Realms material; they are not active UI or incomplete functionality.
- Place sounds (2026-10-11): 66 of 618 blocks play their break sound when placed, not their own place sound, because the hash-checked block reference (`Reference/minecraft-blocks-26.3`) carries only the files of the break and hit events. The 28 place events affected include deepslate and its ores and variants, amethyst and its buds, calcite, sculk, sculk catalyst, the copper bulbs, lodestone, resin, cinnabar, sulfur, suspicious sand and gravel. Extending the reference with their place files is Jesus's call (`Scripts/Editor/BreakImportData.py` prints the list).

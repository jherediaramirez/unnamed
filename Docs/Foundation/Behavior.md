# Scale, movement and action contracts

All baseline constants refer to the hash-pinned 26.3 client in Reference.md. One block = one meter = **100 Unreal cm**. Pure simulation uses cm positions and **cm per reference tick** velocity; 20 reference ticks/s. Telemetry differentiates displacement/tick, post-drag stored velocity, and cm/s. No CharacterMovement `MaxWalkSpeed` guesswork or global 20 FPS cap.

Binding policy: the project uses **Left Shift sprint and C crouch**, retaining the personal layout established in the existing menu. The researched vanilla keys remain in the Controls reference matrix. All movement contracts below act on logical requests, so changing a binding does not change acceleration, jumping, sprint eligibility or crouch collision.

## Coordinates and poses

World-aligned collision box width/depth 60 cm. Pawn actor origin is feet (explicit design choice); collision center is feet + half-height; visual camera is distinct. Standing height 180/half-height 90/eyes 162 cm; crouch 150/75/127 cm. A centered standing capsule would require camera +72 cm, crouch +52 cm; this pawn uses feet-based placement instead. Swimming/crawling/fall-flying/spin pose 60×60×60 cm, eyes 40; sleeping 20³/eyes20; dying20³/eyes162 as registered; flight standing dimensions; riding uses the ordinary pose plus vehicle attachment (no universal mounted height). These extra systems are deferred.

Given rebased Unreal feet P and origin O in absolute cm, absolute P is P + World.OriginLocation. MC=( (absP.X-O.X)/100, (absP.Z-O.Z)/100, (absP.Y-O.Y)/100 ). Reverse subtracts rebasing offset. Integer blocks floor each component: -.1 → -1. UE +X east/+Y south/+Z up. Minecraft yaw = normalized(UE yaw - 90°); south0, west90, north±180, east-90. Minecraft pitch = -UE pitch (down positive). Both directions and round trips must be tested.

## Collision choice

60 cm radius-diameter capsule and 60 cm box have different corner clearance. Against a cube whose corner is (0,0), a center (-22,-22) has circle distance 31.11>30 cm (capsule clears) while the square extends to (+8,+8) (overlap). Gap59 cm blocks both; gap61 clears both. These are analytic geometry comparisons, not yet Chaos runtime measurements. Choose a world-aligned UBoxComponent pawn with a deterministic axis-clipping solver against lab cuboids; camera yaw never rotates the box. This handles the reference's relevant rectangular collision cases without capsule tuning. General arbitrary meshes, slopes and moving platforms require a later collision provider; do not claim equivalence for them.

## Simulation order and policies

At each 50 ms step: decrement sprint/jump timers; resolve input/eligibility/pose; cut horizontal stored velocity below .003 blocks/tick and vertical absolute velocity below .003; apply held jump if grounded and cooldown0; accelerate; clip against world AABBs (vertical then greater horizontal magnitude); choose an improving legal step candidate ≤.6 blocks; zero collided velocity components; gravity; multiply horizontal velocity by pre-move grounded friction .6×.91 or airborne .91, vertical by .98. Base ground acceleration .1 blocks/tick², sprint ×1.3, air .02/.026; jump vertical .42 blocks/tick plus sprint facing impulse .2; gravity .08 blocks/tick²; held jump cooldown10, release resets cooldown. Landing changes grounded state independently of sprint intent. No coyote time, buffering, slide or survival simulation.

Input direction: (right-left,forward-back), normalize; scale .98 and sneak factor .3 when moving slowly; multiply length by reciprocal max absolute normalized component, capped at1. Cardinal steady walk ≈4.31718 blocks/s; sprint≈5.61234; sneak≈1.29515. Diagonal walking reaches≈4.40529 blocks/s, and diagonal sneak≈1.83163: these 26.3 differences are deliberate source behavior. Air movement retains momentum; stopping uses drag/cutoff, not immediate zero.

Sprint: an eligible forward edge arms a 7-tick configurable timer; a second eligible edge while remaining timer>0 starts sprint. The current logical forward binding supplies the edge. Holding the logical sprint request with positive forward also starts sprint. The resolved sprint latch survives sprint-key release. It ends for no forward, food/mobility eligibility failure or non-minor horizontal collision. Crouch blocks starting; source does not directly stop an already-running sprint merely because crouch is requested. Input requested state and resolved state are separate. Baseline eligibility assumes alive, mobile, sufficient food, no water/riding/effects/item slowdown. A future eligibility provider supplies those facts.

Sneak Hold/Toggle controls requested crouch. Resolve 150 cm pose when requested or standing is blocked; release under ceiling retains crouch. Never enlarge collision through ceiling. At/downward movement while near ground, shrink unsupported horizontal offsets by .05 blocks until supported within .6 below; rising jump bypasses edge restraint. Crawling fallback remains deferred.

Auto-jump defaults OFF, matching source. The primitive-lab adapter uses the source eligibility/facing/headroom/lookahead/height rules; non-cuboid and fluid/block-factor behavior is outside the fixture. Queue for following reference step, not a render-frame jump.

Accumulator runs at most five steps per frame; excess wall time is discarded and counted, with no teleport catch-up. Render interpolates previous/current feet and tick-smoothed eye/FOV; mouse yaw/pitch updates per rendered input frame with accumulated delta×8(.6s+.2)^3×.15 and no delta time. Rate-based gamepad look is deferred. Vertical reference FOV70 converts to horizontal `2 atan(tan(v/2)*aspect)`; apply current aspect each frame. Bobbing and cinematic camera need honest approximation/deferred labels.

## Routing, actions and cancellation

Priority: binding capture > text/menu focus > diagnostic chords > gameplay. UI focus, cursor/input mode and action suppression accompany contexts. One native Enhanced Input profile remains authoritative. Context loss, focus loss, rebinding and possession changes cancel actions/toggles and suppress still-held physical keys until released. This deliberately differs from vanilla's optional restored toggle states to meet this task's no-stale-input requirement. Events selecting a binding cannot activate the player. Reject same-context/same-modifier duplicates; allow gameplay/debug chord sharing. Reserved Escape exits; fixed modifier Control for stack drop does not follow rebound sprint; inventory Shift does not follow rebound sneak. Debug modifier and overlay can intentionally share F3.

Target: eye ray, block reach4.5/entity3.0 blocks (strictly less); nearest entity only before occluding block, measured to hit point. Baseline ordinary player, no creative reach bonuses or item range overrides. Action request has type, phase, target kind/id, hand and eligibility; result has accepted/reason. Attack press chooses entity attack or block break; holding sustains block fixture, release/target change/context loss cancels. Active use rejects attack/pick; active break rejects use. Use tries target interaction, then held item, main then offhand; successful/failed use stops priority descent, pass permits next branch. Sneak bypasses ordinary block interaction when a hand contains an item. Fixture tokens exercise these outcomes but are not an inventory/mining/combat system. Use repeat every4 ticks; drop1 or Ctrl+drop stack; swap main/offhand once; pick chooses diagnostic matching slot or rejects absent target.

Hotbar1-9 individually rebindable; wheel wraps 0..8, direction and fractional sensitivity separate from menus. Inventory is a fixture panel, chat/command is local editable text with no network backend. F1 hides gameplay HUD; F2 creates real screenshot; F5 cycles camera-only diagnostics. F3 release toggles unless consumed as chord; F3+F6 opens options and never switches perspective. F3 options/scale/sections persist alongside native input settings; passive overlay never takes focus. No player in menu means explicit "no player".

Predeclared tolerances: steady speed ≤1%; jump apex≤.02 blocks; airtime≤1 reference tick; pose/eye dimensions≤.001 blocks; coordinate round trip≤1e-7 cm; collision clearance and input routing explicit pass/fail. Cadences30/60/120 FPS. Reference recurrence is source-derived until compared with observed vanilla runtime. Revise targets only with recorded justification.

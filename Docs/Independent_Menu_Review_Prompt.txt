A. IMPLEMENTED REAL FUNCTIONALITY

- Fullscreen: switches the actual standalone window between windowed and
  borderless fullscreen. It is NOT exclusive monitor-mode switching. F11 and
  Alt+Enter use the same adapter. Returning restores the windowed client size.
- Max Framerate: changes the engine cap, 10..260 in increments of 10; the source
  260/Unlimited choice maps to engine cap 0. Default 120. Browser/panorama update
  rates are separate and are not proof of engine cadence.
- VSync: changes/readbacks engine r.VSync. Default ON. Driver-level tearing and
  forced driver overrides still require physical-machine acceptance.
- GUI Scale: changes the actual integer menu layout scale. Auto is 0; explicit
  preferences are bounded/clamped for viewport layout, reserving 416x240 logical
  pixels. A smaller window must not destroy a stored larger-scale preference.
- Menu Background Blur: changes actual panorama/fallback blur, range 0..10,
  default 5. Shared by Video and Accessibility. Main remains unblurred. A mock
  graphics preset must not overwrite this real preference.
- Persistence: those five implemented values save on completed change and restore
  on the next game launch. Windowed dimensions are additional restoration data.
  In a normal package the dedicated file is
  Packages\MenuNoRealmsDevelopment\Windows\Unnamed\Saved\Config\MenuVideoSettings.ini.
  This is not persistence for every unfinished setting.
- Hard Reset: temporary DEBUG-ONLY button at the very bottom of Video Settings,
  matching the textured primary main-menu button style, centered, 200x20 logical
  pixels. Confirmation is required. Cancel/Escape does nothing. Confirm restores
  the five defaults, saves them, returns to windowed, and reloads the document.
  Reload also recreates mock settings, bindings, locale, packs, sample lists and
  drafts. It PROTECTS worlds/player data/unrelated saves; it is not a directory
  wipe. No real world/progression systems exist. The user confirmed this policy.
  -ExcludeDebugTools / --without-debug-tools omits this temporary UI. That is not
  a security restriction on the native reset service or a final Shipping policy.
- Quit Game: main-menu action performs normal Unreal standalone shutdown. It
  locks new video changes, drains queued edits, waits for settled native settings,
  flushes the dedicated preference file, and requests normal exit on a controller
  tick. It does not force-kill the process or reset preferences. A failed flush
  cancels quitting and allows a recoverable retry. Duplicate requests are guarded.
  Quit is disabled/rejected inside Unreal Editor Play so it cannot close the editor.

Native window/FPS/VSync controls and Hard Reset require a ready standalone window;
embedded editor Play protects those engine-global settings. GUI/blur remain usable
in Play. Capability-driven disablement is intentional, not a broken button.

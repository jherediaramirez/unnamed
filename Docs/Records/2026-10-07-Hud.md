## Implementation

`Scripts/Editor/ImportHud.py` imports all 194 original PNGs under `/Game/Hud/Textures`, preserving namespace-relative names. `DA_HudAssets` contains source path/hash, soft texture reference, dimensions, frame dimensions/indexes/ticks, original MCMeta (including nine-slice and interpolation), semantic role and import preset. The registry also contains 95 printable ASCII glyph metrics derived from the original alpha and `include/default.json`; the earlier space provider supplies space advance 4. Originals are never rewritten. On a rerun, existing textures/settings and canonical metadata must match; assets are not saved or reimported.

Pixel assets use nearest filtering, UI RGBA compression, sRGB, no mips, no padding/resizing, clamped UVs and residency. Metadata-marked blurred overlays use bilinear filtering; fire/portal and glint retain repeat addressing. Animated/sliced/deferred assets retain metadata but are not displayed. Their eventual materials, animation and compositing remain future work. `/Game/Hud` is explicitly always cooked. Asset roots are owned by `UUnnamedProjectSettings` and `Scripts/Editor/ProjectPaths.py`; the importer is in the Foundation build loop.

`Source/Unnamed/Hud` separates pure layout/selection (`HudModel`), temporal history (`FHudPresentation`), test data (`FHudPreview`), draw construction (`HudDrawList`), the Foundation/settings adapter (`UHudPresenter`) and a passive leaf (`SHudView`). Brushes and UObject texture references are retained; painting consumes draw commands and never reads or changes gameplay. The adapter samples existing non-evented fixture/settings values at up to 20 Hz, with immediate visibility changes. Slate paint invalidation occurs only when commands or scale change. F3 retains its existing independent 10 Hz text path.

`UFoundationHud` has one overlay containing the leaf and the unchanged F3 diagnostic widget. The text hotbar, plus-sign crosshair and ESC/F3 hint are removed. F1 hides the presentation including PREVIEW, leaving F3 independent. Menus/panels/capture suppress the passive HUD through `IsGameplay`; perspective gates the crosshair. Nothing in this widget takes focus or handles input.

## Remaining boundaries

- No vanilla capture folder existed at the start of this run. Source-derived geometry, verified original pixels and rendered Unreal evidence do not establish played-client visual equivalence.
- Crosshair and its indicator use ordinary alpha blending. Java's background-dependent inverse blend and the 3D debug-axis crosshair are not implemented.
- Jitter uses stable tick-seeded bounded noise, not Java's exact shared RNG sequence. Bubble-pop sound is not implemented.
- ASCII only; full Unicode, localization, rich item names, real item models/glint/durability/cooldowns and pickup animation are deferred.
- Effects, bosses, locator, mount, toasts, chat, player list, spectator selector and camera overlays are import-only. Mount-row displacement and context selection have pure tests, but no mounted/locator UI is presented.
- Gameplay authority, networking, real modes, inventories/resources and their persistence are absent. OS hardware input, alternate keyboard layouts, subjective feel and broader Windows DPI coverage remain distinct from application-input probes.

Milestone 2 is not started.

# Chat commands: /gamemode, /give, /tp, /time, /kill (survival step 15, 2026-10-14)

Lane `feature/survival-feel` (worktree `C:\dev\projects\Unnamed-feel`), survival track T4. Commands typed in the chat now run with vanilla's syntax and its feedback and error lines, and the chat lines draw bottom-left in the HUD's font. The full description is in [Docs/Commands.md](../Commands.md).

## Decisions (vanilla first, flagged; accepted by the manager)

1. **`/time`:** 26.3's own replies through `FVoxelWorldClock::RunCommand` ("Set minecraft:overworld to time marker minecraft:night"). `query` takes `time|day|gametime`; `daytime` is the incorrect-argument error.
2. **Adventure and Spectator** are refused with a red non-vanilla line. Setting the mode already set prints nothing (vanilla's silent failure; the wiki is the only source).
3. **The player's name** is the stand-in "Player"; names match in any case.
4. **`/tp`:** vanilla's `%f` positions, +0.5 on whole x and z, and vanilla's bounds.
5. **Errors:** vanilla's two lines (the message, then the 10-character context with `<--[HERE]`), without the underline or italic.
6. **Layout:** minecraft.wiki chat settings, provisional: 320 px width, 9 px rows, 10 rows closed and 20 open, 40 px bottom offset, the 50% band. The fade is linear over the last of the 10 seconds.
7. **Death messages** in chat are left to step 11.

## Pre-commit review (two Sonnet 5.5 reviewers, split by path; the diff is over 1,500 lines)

- **Fixed:**
  - a bare `-` or `.` parsed as a number (`/tp . . .` teleported; `/time set -` set 0). `IsValidNumber` now needs a digit; tests `tp . . .` and `time set -`;
  - `minecraft:` was matched case-insensitively. It is now case-sensitive, and upper-case markers don't exist (test);
  - the presenter rebuilt and compared every chat line every frame. It now uses a revision plus a 1/20 s fade step;
  - a wrapped row could start with the breaking space. It is now dropped (test);
  - a per-character `FString` in the wrap and a per-line array copy;
  - the probe left apples, the clock, F1 and chat lines behind. The restore case puts them back.
- **Accepted, documented:**
  - an int32 tick cap on `/time` arguments;
  - `Unknown item 'minecraft:'` for upper-case ids;
  - `/gamemode` resets the lab's supply, wear and creative-inventory options (as a saved world's mode does);
  - the player's simulation stops under the open chat, as under every panel before. Vanilla's world keeps running while you type, and so does the world clock here.
- **Before the review**, earlier native runs caught two more:
  - UE's `FString ==` is case-insensitive, so `/GameMode` ran. Every literal is now `Equals(..., CaseSensitive)`;
  - a target read kept the default `@s` when a name followed, so `/kill Steve` killed the player. `ReadTarget` now resets.
